## ⭐ Proyecto de Programación: problema restringido de tres cuerpos

[`Proyecto de Programacion/ProyectodeProgramacionNatalia.ipynb`](Proyecto%20de%20Programacion/ProyectodeProgramacionNatalia.ipynb)

Estudio del movimiento de una masa pequeña bajo la atracción de dos cuerpos grandes que giran uno alrededor del otro, en el sistema de referencia que rota con ellos:

- **Potencial efectivo** $V_{eff}(x, y)$ en 1D, 2D (mapa de contorno) y 3D (superficie).
- **Trayectorias** de la masa pequeña, obtenidas al integrar las ecuaciones de movimiento con `scipy.integrate.solve_ivp`.
- **Caso Tierra–Luna**, con constantes y condiciones iniciales proporcionales a la órbita de la Luna.

Para ejecutarlo: ábrelo en [Google Colab](https://colab.research.google.com/) o en Jupyter (`pip install numpy scipy matplotlib`).
